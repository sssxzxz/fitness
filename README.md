# 身体观察系统（第一版）

一个本地运行的 3D 人体解剖查看器，电脑和手机都能用。用途：认出不适的是哪块肌肉，用标准动作确认它，并长期记录。

## 启动

1. 需要 Python 3.7+（Anaconda 自带即可）或 Node.js 18+，有其一就行：[Python](https://www.python.org/) / [Node.js](https://nodejs.org/)
2. 双击启动脚本（Windows 脚本会自动找 Node → Anaconda 的 Python → 系统 Python）：
   - Windows：`start-windows.bat`
   - macOS：`start-mac.command`（第一次运行如果被系统拦截，右键 → 打开）
   - Linux：`./start-linux.sh`
3. 浏览器会自动打开 http://localhost:8686
4. 手机连同一个 Wi-Fi，打开启动窗口里显示的 `http://192.168.x.x:8686` 地址

窗口开着时服务一直在运行，关掉窗口就停止。Windows 第一次运行时防火墙可能会弹窗，需要允许"专用网络"，手机才能连上。

> 只在家里等可信的 Wi-Fi 下使用。服务没有密码，同一网络里的设备都能访问。

## 功能

| 功能 | 说明 |
|---|---|
| 7 个系统图层 | 骨骼、肌肉与筋膜、关节与韧带、心血管、神经与感官、内脏、淋巴。每层可单独开关、调透明度，用到时才加载 |
| Innerbody 式交互 | 选中结构旁出现浮动标签（中英拉丁名、🔊朗读、ⓘ详情、隐藏 / 淡化此结构 / 淡化其他全部 / 只看它）；选择 / 隐藏 / 淡化三种工具；层次滑块由外向内逐层淡化肌肉直到骨骼；撤销 / 重做 / 重置；结构树（每行显示开关和“⋮”菜单，可筛选可见 / 已隐藏）；绘图标注并下载截图；Innerbody 同款快捷键（按 Shift+/ 查看）；长按飞到结构；Ctrl/Shift 多选；全屏 |
| 动作动画（原型） | 弯举、锤式弯举、臂屈伸三个动作有 3D 肌肉动画：在「训练」页打开动作，点「▶ 动作动画」。可播放 / 暂停 / 拖动进度 / 调速 / 选左右侧；发力肌肉按阶段变色（蓝 = 向心收缩、紫 = 停顿、绿 = 离心收缩），协同肌肉橙色；播放时点选、隐藏、淡化、层次等全部可用 |
| 写实材质 | 肌肉沿各自长轴的纤维纹理、湿润光泽；肌腱筋膜白色光泽；骨骼细腻；淡化时变为白灰半透明（同 Innerbody）；浅色 / 深色背景可选；高精度模型 |
| 视角操作 | 左键拖动旋转；右键/中键拖动或 Shift+左键拖动平移；滚轮朝鼠标位置缩放；**双击某处把它移到画面中心**，之后绕它旋转。手机：单指旋转、双指平移/缩放、双击居中 |
| 点选识别 | 点击任意结构，显示中文名、英文名、拉丁名、左右侧、所属分组和英文释义 |
| 隐藏 / 只看它 / 隐藏同组 / 撤销 | 一层层剥开去看深层结构（快捷键：H 隐藏，Esc 取消选择，Ctrl+Z 撤销） |
| 透视模式 | 被选中结构以外的部分变成半透明，深层肌肉也能看清 |
| 搜索 | 中文、英文、拉丁名都能搜 |
| 重点肌肉（37 个条目） | 头颈和躯干。每条包含抗阻确认动作、拉伸确认、触诊定位、与易混肌肉的区分、常见不适表现、解剖信息、训练动作 |
| 确认动作详情 | 每个动作都有起始姿势、分步骤、阳性/正常判断、常见错误、注意事项 |
| 视频 / 图片 / 笔记 | 每个动作卡片上点「✎ 添加视频 / 图片 / 笔记」：可上传本地视频或图片（保存在 `userdata/media/`），或粘贴 B 站 / YouTube / 视频网址，可设定从第几秒开始播放 |
| 逐项测试 | 点「▶ 开始逐项测试」，按顺序做完抗阻、拉伸、触诊，每项按左右侧点选「正常 / 痛 / 无力」，最后自动给出初步提示并保存为记录 |
| 对症处理 | 每块重点肌肉有放松、拉伸、强化、日常调整四步方案，以及急性期、恢复期、何时就医的处理原则；拉伸和强化动作可以直接点开查看 |
| 健身模块（「训练」页） | 62 个中文动作，每个动作都对应到具体肌肉（主要发力肌肉蓝色高亮，协同肌肉橙色）；可记录每组重量和次数；统计近 7 天各肌肉的训练组数；每块肌肉的面板里会列出能练到它的动作 |
| 中英文名 | 骨骼和肌肉全部有中文名；「图层」页可以开关英文名和拉丁名 |
| 不适记录 | 记录肌肉、侧别、程度、感觉、诱发动作、诱因和备注。可以看单块肌肉的变化曲线，也可以选择把肌肉按近 30 天不适程度或近 7 天训练量着色；还能记录做了哪些处理、效果如何。支持导出 JSON/CSV |

所有个人数据都在 `userdata/` 文件夹：`logs.json`（不适记录）、`workouts.json`（训练记录）、`custom.json`（你添加的视频链接和笔记）、`media/`（上传的视频图片）。电脑和手机共用这一份；备份或升级新版时，把整个 `userdata` 文件夹复制过去即可。

## 数据说明与核对

- 3D 模型和英文释义来自 [Z-Anatomy](https://www.z-anatomy.com/)（CC BY-SA 4.0），源头是 BodyParts3D 和 Wikipedia。模型做了减面和压缩。
- **已修正的源数据错误**：Z-Anatomy 把斜方肌的"降部（上斜方肌）"和"升部（下斜方肌）"标反了，转换时已对调（见 `tools/fix_index.py`）。发现其他问题可以继续加到这个脚本里。
- 重点肌肉的中文内容（`app/data/muscles.js`）是整理的初稿，建议对照以下资料核对：Kendall《Muscles: Testing and Function》、[Kenhub](https://www.kenhub.com/)、[Physiopedia](https://www.physio-pedia.com/)。
- 本系统用来定位和记录，**不能代替医生诊断**。应用内"重点肌肉"页底部列出了需要就医的信号。

## 扩展

- **重新计算肌肉层次**（层次滑块用）：`tools/peel.js` 在浏览器里对模型做“剥洋葱”式可见性计算，结果存为 `app/data/layers.json`。
- **加动作动画**：在 `app/anim.js` 的 `ANIMS` 里添加，键名与动作库 id 相同即可自动出现「动作动画」按钮。目前骨架只有肘关节，其他关节在后续版本加入。
- **加健身动作**：编辑 `app/data/exercises.js`。
- **改对症处理方案**：编辑 `app/data/care.js`。
- **改详细步骤**：编辑 `app/data/tests-detail.js`（按肌肉 id → 动作名组织）。
- **加肌肉条目**：在 `app/data/muscles.js` 里照现有格式添加。`bases` 填模型里的英文结构名，在应用中点击该结构就能看到。
- **加中文名**：编辑 `app/data/zh-terms.js`。
- **重新生成模型**（比如调整精度）：用 `tools/` 里的脚本。需要 Blender 的 Python 模块 `bpy`（Python 3.11）和 `@gltf-transform/cli`：
  ```
  python za_export.py <Z-Anatomy/Startup.blend> <输出目录> all
  python za_defs.py  <Startup.blend> <输出目录> app/data/definitions.json
  gltf-transform meshopt 输入.glb app/models/xxx.glb
  ```
